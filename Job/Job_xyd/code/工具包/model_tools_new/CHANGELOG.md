## 版本规范说明

### 版本号格式
遵循 `主版本号.次版本号.修订号` 格式：

- **主版本号**：当你做了不兼容的 API 修改
- **次版本号**：当你做了向下兼容的功能性新增
- **修订号**：当你做了向下兼容的问题修正

### 更新类型
- 🎉 重大功能
- ✨ 新功能
- 📈 性能提升
- 🔧 改进
- 📚 文档
- 🧪 测试
- 🐛 bug修复
- 🔒 安全
- 🏗️ 架构
- 🔌 扩展性

### 重要提醒
- 查看 [升级指南](docs/upgrade_guide.md) 了解版本间的迁移方法

- 建议在测试环境中充分验证后再升级生产环境
